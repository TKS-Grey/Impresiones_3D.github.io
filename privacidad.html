Política de Privacidad

Última actualización: 7 de septiembre de 2026

1. Información general

En Impresiones 3D AML nos preocupamos por la privacidad de las personas que utilizan nuestro sitio web. Esta política explica qué información puede recibirse mediante las funciones del sitio y para qué se utiliza.

2. Información que recopilamos

Cuando una persona realiza una solicitud de impresión 3D, el formulario puede recibir los siguientes datos:

  • Nombre.
  • Apellido.
  • Correo electrónico institucional.
  • Curso.
  • Tamaño solicitado para la figura.
  • Descripción o mensaje relacionado con la solicitud.
  • Archivo de modelo 3D enviado voluntariamente por el usuario.

3. Uso de la información

La información recibida se utiliza para gestionar y revisar las solicitudes de impresión 3D, identificar correctamente al solicitante, revisar el modelo enviado y contactar al usuario cuando sea necesario para coordinar aspectos relacionados con su solicitud.

4. Archivos enviados

Los archivos de modelos 3D enviados mediante el formulario se utilizan para revisar si el modelo es adecuado para el proceso de impresión. El proyecto no garantiza que estos archivos permanezcan almacenados indefinidamente.

5. Cuentas de usuario

El sitio puede permitir la creación de cuentas mediante Firebase Authentication. La información asociada a una cuenta se utiliza para permitir el inicio de sesión y las funciones relacionadas con el usuario.

6. Historial de entregas

Cuando corresponde, el sistema puede utilizar información asociada a la cuenta para mostrar un historial de entregas. Este historial puede incluir información como el nombre de una figura, una fecha, una descripción y una fotografía asociada a la entrega.

7. Servicios de terceros

El sitio utiliza servicios de terceros para determinadas funciones, entre ellos Firebase para autenticación y almacenamiento de datos, y FormSubmit para el procesamiento y envío de formularios. Estos servicios pueden tratar información de acuerdo con sus propias políticas y condiciones.

8. Seguridad

Intentamos manejar la información recibida de forma responsable. Sin embargo, ningún sistema conectado a Internet puede garantizar una seguridad absoluta frente a todos los riesgos existentes.

9. Menores de edad

El proyecto está orientado principalmente a una comunidad educativa, por lo que algunas personas que utilizan el sitio pueden ser menores de edad. El sitio solicita únicamente la información necesaria para las funciones que ofrece.

10. Contacto

Si tienes preguntas relacionadas con esta Política de Privacidad o con el tratamiento de la información proporcionada mediante el sitio, puedes visitar nuestra página de contacto.
